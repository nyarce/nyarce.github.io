## 🚀 Day 0: Contract Signed (Immediate Actions)

**Within 24 hours:**
1. **Create ClickUp project** from template (or manually if not automated yet)
2. **Submit mapping request** to Map Specialist team
   - Attach shapefiles if provided by Sales, otherwise provide Parcel ID
   - Target completion: 4 days
3. **Pre-book soil sampling appointment** with EarthOptics
   - Use rancher availability matrix from Sales
   - Confirm date/time with rancher via preferred contact method
   - Target: Schedule within 20 days, complete by Day 34
4. **Pre-book GMP consultation** with Understanding Ag
   - Requires: Mapped ranch (Day 4)
   - Target start: Day 4 | Target completion: Day 34
5. **Send welcome email** to rancher with timeline overview and your contact info

## 📅 Weekly Monitoring (Manage All 10 Ranches)

**Monday Morning Dashboard Review (30 min):**
- Review ClickUp Board View: Which ranches are in each stage?
- Identify at-risk ranches (yellow/red status indicators)
- Check upcoming third-party appointments (next 7 days)

**Daily Check-ins (15 min):**
- Check for completed tasks → Trigger next step
- Respond to rancher questions (aim for <24hr response time)
- Follow up on overdue tasks (anything >2 days overdue)

## 🔄 Stage-by-Stage Workflow

### Stage 1: Mapping (Day 0-4)
- **Monitor:** Map Specialist completion status
- **Action:** Once complete, confirm GMP consultation can start on Day 4

### Stage 2: Parallel Execution (Day 4-34)
- **Soil Sampling Track:**
  - Day 0-20: Monitor scheduling confirmation
  - Day 20-34: Monitor EarthOptics completion, follow up if delayed
- **GMP Consultation Track:**
  - Day 4: Confirm Understanding Ag has started consultation
  - Day 15: Mid-point check-in with consultant and rancher
  - Day 34: Confirm consultation complete

**[QUESTION: What does "completion" look like for soil sampling and GMP? Is there a deliverable/report? Who receives it?]**

### Stage 3: GMP Delivery (Day 34-48)
- **Monitor:** Understanding Ag delivers finalized GMP to rancher
- **Action:** Once delivered, schedule PastureMap training

### Stage 4: Training (Day 42-52)
- **Action:** Book training with PastureMap Specialist
  - Phase 1 (optional): Early training with sample data
  - Phase 2 (required): Applied training using rancher's actual data
- **Target:** Complete by Day 52

**[QUESTION: What does PastureMap training involve? Is it a single session or multiple? Who from GRC delivers it?]**

### Stage 5: Project Start Date (Day 48-53)
- **Action:** Once all tasks complete, notify MRV Team
- **MRV Team:** Establishes Project Start Date (3-5 days)
- **Final Step:** Notify rancher of official Project Start Date

## 💡 Tips for Managing 10 Concurrent Ranches

1. **Batch similar tasks:** Schedule all third-party appointments on Mondays, all rancher check-ins on Wednesdays
2. **Use templates:** Pre-written emails for welcome, appointment reminders, training invites, completion notifications
3. **Set recurring reminders:** 3 days before any third-party appointment, send confirmation to rancher
4. **Track blockers immediately:** Don't let issues sit - escalate within 24 hours
5. **Celebrate wins:** When a ranch completes onboarding, notify the team and congratulate the rancher
