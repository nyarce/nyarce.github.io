# Rancher Onboarding Playbook
**Managing 10 Concurrent Ranches**

---

## Coordinator Operating Principles

**1. Single Point of Contact**
- Coordinator owns the entire journey from contract signature to Project Start Date
- Rancher has one consistent contact - no handoff confusion
- Coordinator acts as Project Manager for all internal and third-party coordination

**2. Proactive Scheduling (Day 0)**
- Receive handoff package from Sales with rancher scheduling data (seasonal availability, weather windows, contact preferences)
- Book soil sampling and GMP consultation appointments immediately upon contract signature
- Submit mapping request with pre-collected shapefiles (if available)

**3. Dependency-Based Monitoring**
- Track all 10 ranches in project management dashboard (Monday.com/ClickUp)
- Monitor parallel processes: Soil sampling (Day 0-34) and GMP consultation (Day 4-34) run simultaneously
- If one task delays, auto-adjust downstream deadlines (e.g., soil sampling +5 days → Project Start Date +5 days)

**4. Status-Driven Actions**
- **Green (On Track):** Monitor weekly, no action needed
- **Yellow (At Risk):** Daily check-ins, identify blockers
- **Red (Overdue/Blocked):** Escalate within 24 hours to manager or vendor

**5. Batch Similar Work**
- Schedule all third-party confirmations on Mondays
- Conduct rancher check-ins on Wednesdays/Thursdays
- Review full dashboard every Monday morning (30 minutes for 10 ranches)

**6. Escalate Early**
- Any task >2 days overdue → Notify manager
- Third-party vendor delays >5 days → Escalate to vendor relationship owner
- Rancher unresponsive after 3 contact attempts → Escalate to Sales for re-engagement

## Weekly Workflow (10 Ranches)

**Monday Morning (30 min):**
- Review dashboard: Which ranches are in each stage?
- Identify yellow/red status ranches requiring attention
- Confirm upcoming third-party appointments (next 7 days)

**Daily Check (15 min):**
- Check for completed tasks → Trigger next step
- Respond to rancher/vendor questions (<24hr response time)
- Update task status in dashboard

**Wednesday/Thursday (2-3 hours total):**
- Conduct weekly rancher check-ins (15 min each, ~6 ranches/week on rotation)
- Follow up on pending items (missing shapefiles, training scheduling, etc.)

**Friday Afternoon (15 min):**
- Review week's progress, update status for all 10 ranches
- Flag any at-risk ranches for Monday escalation if needed

## Key Success Metrics

- **Average time from contract to Project Start Date:** Target 53-73 days (vs. current 103 days)
- **% of ranches completing on time:** Target 80%+ within proposed timeline
- **Escalation rate:** <20% of ranches require manager intervention
- **Rancher satisfaction:** Single point of contact improves communication clarity

## Tools & Integrations

**Core Tool:** Monday.com (or ClickUp)
- Ranch onboarding template with all 8 steps pre-configured
- Task dependencies and automated deadline adjustments
- Color-coded status tracking across 10 concurrent ranches

**Integrations:**
- **CRM:** Contract signed → Auto-create Monday.com board for new ranch
- **Calendar:** Third-party appointments sync to coordinator's calendar
- **Communication:** Slack/Email notifications for task updates and overdue alerts
